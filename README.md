# La Noche Estrellada

Escena animada inspirada en *La noche estrellada* de Vincent van Gogh (1889), hecha solo con HTML, CSS y JavaScript (canvas), sin imágenes.

**Demo:** https://lgmiguel12.github.io/noche-estrellada/

## Características

- Cielo pintado con miles de pinceladas que siguen un campo de remolinos.
- Pinceladas vivas que fluyen por el cielo; al mover el mouse se forma un remolino nuevo.
- Luna, estrellas con halos, estrellas fugaces, pájaros, ventanas y faroles que parpadean.
- Ocupa toda la pantalla en PC (la escena se extiende a lo ancho) y conserva la composición original en móvil.
- Respeta `prefers-reduced-motion`.

## Uso

Abre `index.html` en el navegador. No necesita dependencias ni compilación.
